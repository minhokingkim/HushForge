# HushForge

HushForge is a self-orchestrated, autonomous platform engine that dynamically adapts to workload fluctuations through auto-scaling and self-healing capabilities.

With HushForge, you get a lightweight tool that stays out of your way.

**What you get**

- HushForge is a self-orchestrated, autonomous
- platform engine that dynamically adapts
- to workload fluctuations through auto-scaling

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/HushForge.git`
2. `cd HushForge`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
